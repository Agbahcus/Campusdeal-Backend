2) Sendchamp SMS showing rejected

The two biggest things to verify on Sendchamp are:
Sender ID is approved/active — Sendchamp says a sender ID must be approved before it works without restrictions: https://docs.sendchamp.com/channels/sms/create-a-sender-id
Recipient number is in international format — their OTP docs say the mobile number must be like 2348012345678 (no +): https://docs.sendchamp.com/product/verification/sending-an-otp
I patched accounts/sendchamp_service.py so Nigerian numbers like 080... are converted to 234..., and I made the SMS route configurable via SENDCHAMP_ROUTE.
If reports still show rejected after that, check:
you’re using the live access key,
the Sender ID is approved,
the number is not being sent in local format,
and try the same destination number from the Sendchamp dashboard to isolate provider setup vs app code.
